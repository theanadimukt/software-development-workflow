# /webperf routing

Goal: measure a user-visible performance problem, identify its cause, and prove an improvement.

Start with `performance-optimization`. Add `browser-testing-with-devtools` for browser measurements, `frontend-ui-engineering` for rendering and interaction concerns, `observability-and-instrumentation` when production telemetry is needed, and `source-driven-development` for platform-specific behavior. Do not optimize without a baseline and a verification target.
