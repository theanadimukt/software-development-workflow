# /architect routing

Goal: choose sustainable boundaries, responsibilities, and interfaces before changing implementation.

Start with `improve-codebase-architecture` and add `api-and-interface-design` whenever the design exposes or changes an interface. Add `documentation-and-adrs` for consequential, durable decisions; `deprecation-and-migration` for compatibility or migration paths; `security-and-hardening` for trust boundaries; and `source-driven-development` for framework or vendor constraints.

Do not turn a local refactor into an architecture exercise. Select only the skills demanded by the decision's blast radius.
