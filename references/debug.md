# /debug routing

Goal: reproduce, isolate, and fix the root cause before changing code.

Start with `debugging-and-error-recovery`. Add `browser-testing-with-devtools` for browser-only symptoms, `observability-and-instrumentation` where missing signals prevent diagnosis, `performance-optimization` for performance regressions, and `source-driven-development` when an external dependency's documented behavior is uncertain. Do not select a specialty until evidence points to it.
